## 尚待外部联调

1. 两套真实 MySQL 5.7.43 数据库已建库、建表并完成账号隔离与 TLS 核验。真实 OSS 大视频上传、跨域 / 自定义域名和应用线上部署仍待外部配置后验证。
2. Mock 按名称验证 JPG / HEIC / MOV / MP4 的字节无损流程，HEIC / MOV 传输固件为二进制测试载荷，尚未覆盖真实 iPhone / Android / 相机 RAW 的全部编码和元数据差异。
3. 中国内地新 OSS 账户的默认域名访问限制须在实际账户确认，仓库已提供自定义域名、V4 与 CORS 配置路径。
4. 浏览器对 HEIC、RAW、HEVC、MOV 的预览依赖平台。系统提供独立兼容预览导入和原件下载，未配置自动转码。
5. Apple MakerNote 与部分厂商 RAW、VFR / 特殊 QuickTime box 可能只得到部分元数据。系统保存已解析 JSON，缺失字段不补造，允许手工修正和双文件配对。
6. 纯 Web 无法强制 iPhone 照片选择器交付相机原件或 Live Photo 全部资源。系统保证所选字节的无损保存，原片导出方式见存储文档。
7. 真实手机 Safari / Android 长时间后台上传、触摸手势和视频解码仍需设备验收。现有验证包含真实浏览器手机尺寸布局，以及 DOM 层长按 / Shift 自动化测试。
8. 本实例是单家庭共享权限模型。成员可编辑整个家庭的内容，访客只读，管理员管理账户、孩子删除与导出。
9. OSS HEAD 的 SHA-256 是客户端声明的对象元数据，上传字节完整性由 OSS CRC64 与浏览器 CRC64 比较，完整 SHA-256 独立审计通过 CLI 逐字节备份完成。
10. 完整备份 / 恢复在维护窗口停写并等待上传结束后运行。便携清单不导出密码、会话和未完成上传授权。物理原件没有应用内永久删除功能。
