## OSS 跨域上传故障验证（2026-11-06）

- 文件选择和任务创建成功，但直传显示 OSS 网络错误时，确认 Bucket CORS 仅允许开发 origin，未覆盖实际站点 origin。补充精确来源后，同一 PUT / Content-Type 预检由 403 改为 200；没有修改上传重试代码。
- WebKit 从实际站点 origin 调用已发布的元数据解析与上传函数，上传合成 JPEG 和约 17 MiB 的合成 MOV，共三个真实 OSS 分片 PUT，全部返回 200，进度到达 100%。任务及签名接口使用临时验收适配，不写入家庭数据库，不使用私人影像。
- OSS 实际合并后验证大小与 CRC64，并重新下载计算完整 SHA-256，全部一致；临时对象已删除。Bucket 仍为 private，未授权来源预检仍返回 403。
- 本轮为云端 CORS 配置修复及文档更新，无应用代码或数据库迁移，不需要重启服务；未重新运行与配置无关的前后端单元测试。WebKit 不能替代 iPhone 真机和移动运营商网络验收。

## 已覆盖的功能

- **时间线与整理：** 拍摄时间与归档日期分离、跨日期追加确认、命名批次、根目录混排、文件夹内部排序、批量移动、正反序分页与筛选、恢复默认排序。
- **孩子与日记：** 多孩子关联、生日和月龄边界、独立头像、共同成长日记、封面与媒体顺序、软删除和恢复。
- **上传与原件：** 分片重试、重复完成、CRC 核验、跨批次去重、Live Photo 双资源、原始元数据保留和缺失值处理。
- **限时分享：** 日期起止和 1–168 小时校验、按天分页、文件夹 / 文件 / 日记排除、签名地址绕过拒绝、压缩视频、链接撤销与过期、创建者权限变化、便携备份不导出链接。
- **权限与会话：** 未登录访问、只读用户写入拒绝、管理员边界、CSRF、Origin、验证码、会话注销与私有文件签名。
- **压缩预览：** 图片缩略图与详情预览、按需查看 HEIC 原件、合成视频转码、视频预览未就绪时不自动加载原件、图片缩放和视频播放控件。
- **备份与环境：** 独立 MySQL 配置、清单导出、旧格式兼容、关系恢复、原件备份校验与损坏备份拒绝。

JPEG EXIF 测试素材是合成色块，设备字段、日期和 GPS 为测试值。视频测试使用合成素材，不包含家庭影像。Mock 测试不能替代真实 OSS、设备和部署链路验收。

## 如何运行

先配置 `.env.test`，使用名称以 `_test` 结尾的独立 MySQL 数据库并完成迁移：

```bash
./scripts/manage.sh test migrate
./scripts/test.sh
```

数据库用例通过外层事务与 SAVEPOINT 回滚隔离，结束后恢复原记录，自增序列可能继续增长。执行前停止连接同一测试库的 API 和预览进程。不要连接生产库运行测试。

仅运行前端检查：

```bash
cd frontend
npm test
npm run build
```

## 尚需按部署和设备验收

1. 私有 OSS 的 RAM 权限、CORS、HTTPS 域名和服务地域配置。
2. iPhone / Android 长时间后台上传、真实触摸手势与原生全屏；浏览器手机尺寸预览不能代替真机测试。
3. 不同设备的 HEIC、MOV、RAW、VFR、MakerNote 和 QuickTime 元数据变体。缺失字段保持为空，必要时使用兼容预览或人工修正。
4. 手机相册选择器是否交付原始文件及 Live Photo 全部资源，纯 Web 应用无法强制其行为。
5. 视频预览工作进程的 FFmpeg 支持、临时磁盘空间与 CPU 资源。转码有原件读取和处理成本，压缩体积不能直接等同于账单节省。
6. 停写后的数据库与原件备份、校验和恢复演练。

OSS HEAD 返回的 SHA-256 是客户端声明的元数据；上传完整性通过 CRC64 比较验证，独立的完整 SHA-256 审计由原件备份流程执行。详见[存储说明](storage-and-metadata.md)及[备份说明](backup-restore.md)。
