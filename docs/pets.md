# 人物与宠物

**简体中文** | [English](en/pets.md) · [返回首页](../README.md)

在“人物与宠物”页面选择“添加人物”或“添加宠物”。人物不局限于孩子，可以是爸爸、妈妈、爷爷、奶奶、外公、外婆、朋友等；“人物关系”可选择常用称呼，也可以填写自定义关系。每份档案均支持独立头像、昵称、简介、颜色、显示顺序和归档。

这些档案用于影像标记，不创建登录账户，也不改变账户权限。

人物档案提供“开启成长时间线”开关。孩子与宠物默认开启；爸爸、妈妈、长辈等其他人物默认关闭，也可手动调整。新建人物选择“孩子”关系时会默认开启，手动选择后不再自动覆盖。

关闭后，档案入口显示“查看相关影像”，仍可标记照片、视频、日记和参与任意 / 全部匹配筛选；不显示年龄标签、年龄阶段、出生当天和成长节点，生日与原有关联继续保留。重新开启后，年龄按生日重新计算。

生日可以留空；开启成长时间线且填写生日后，才提供年龄阶段和生日导航。

## 宠物分类

宠物可以设置分类和品种。分类提供猫、狗、兔子、鸟、鱼、仓鼠、乌龟等常用选项，也支持自定义，如“蜥蜴”。已有宠物的种类直接作为分类使用，品种单独保留。

档案列表和文件选择器都能按“人物”“宠物”及实际存在的宠物分类查找；未填分类的宠物归入“宠物 · 未分类”。搜索同时匹配名字、昵称、人物关系、宠物分类和品种。

## 文件里面都有谁

- 上传整批文件或编辑单个文件时，在“里面都有谁（可多选）”同时选择多个人物和宠物。例如一张合照可同时选择宝宝、爸爸、妈妈和团子。
- 已有文件支持多选后批量追加、解除或替换关联。日记同样支持多个人物与宠物。
- 编辑选择器中的“选中这些档案”会将当前查找到的档案加入已有选择，保留其他关联；“清空选择”可移除全部选择。
- 时间线中点击档案即可筛选；多个档案可选择“包含任意所选档案”或“同时包含全部所选档案”。按分类查找后，点击“筛选这些档案”会切换为这一组档案，例如一次查看所有猫的影像。分类查找本身仅缩小候选列表，不会悄悄改变已选范围。
- 同一份照片、视频或日记会出现在每个关联档案的时间线中，但原件只保存一份，合并浏览时不会重复显示。
- 删除档案仅解除该档案的关联，其他人物或宠物的关联及原件继续保留；删除仍仅限管理员。

## 数据与升级

Alembic `0010` 在现有 `child` 表增加 `relationship`，原孩子档案保留 ID、头像和关联，并标记“孩子”关系。新人物使用 `profile_type=person`，宠物仍为 `pet`，已有 `species` 字段保存宠物分类。为兼容已有数据，继续使用 `/api/children`、`child_ids` 及原关联表名称，它们现在可引用所有人物与宠物。新人物生日可为空；旧客户端省略类型仍按原有孩子接口校验。

`/api/stats` 返回 `people`（全部人物）、`pets`（宠物），并保留 `children` 统计供兼容使用。备份保留人物关系、宠物分类与所有关联；旧备份缺少关系时仍可恢复。

Alembic `0011` 增加 `growth_enabled`。升级时孩子和宠物保留成长功能，其他人物默认关闭；备份保存此开关，旧备份按同样规则恢复。

启动新版后端前，对需要升级的环境执行迁移：

```bash
./scripts/manage.sh test migrate
./scripts/manage.sh production migrate
```

分享仍按日期范围和内容权限控制。公开响应不返回人物关系、人物或宠物档案，也不因此开放原件访问；分享前仍需检查照片中可见的内容及自己填写的标题、日记正文。
