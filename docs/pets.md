# 孩子与宠物

**简体中文** | [English](en/pets.md) · [返回首页](../README.md)

在“孩子与宠物”页面选择“添加孩子”或“添加宠物”。宠物可设置名字、昵称、独立头像、种类、品种、性别、简介、颜色和显示顺序，也可以归档。

宠物生日可留空；补充后，影像和日记会按拍摄日期显示年龄，并支持年龄阶段及生日快捷导航。未知生日不显示年龄，也不提供年龄筛选。孩子档案仍需填写生日。

## 共同的回忆

- 上传时可以同时勾选孩子与宠物；已有照片、视频可以在详情或批量关联中追加宠物。
- 日记也支持同时关联孩子和宠物。进入其中任意一个档案，都能看到这份共同记录。
- 多选筛选可选“包含任意所选档案”或“同时包含全部所选档案”。合照只保存一份原件，全部时间线中不会因为关联多个档案而重复显示。
- 删除宠物档案只解除该档案的关联，孩子的关联、共同日记和原件继续保留。删除操作仍仅限管理员。

## 数据与升级

Alembic `0009` 为现有 `child` 表增加 `profile_type`、`species` 和 `breed`，并允许宠物生日为空。已有档案自动视为孩子。为兼容已有数据和接口，保留 `/api/children`、`child_ids` 及原关联表名称；这些字段现在可引用孩子或宠物。`/api/stats` 分别返回 `children` 与 `pets` 数量。

启动新版后端前，分别为需要升级的环境执行迁移：

```bash
./scripts/manage.sh test migrate
./scripts/manage.sh production migrate
```

便携备份保留宠物类型、种类、品种及关联。旧备份未包含类型时按孩子恢复。回退到旧版会失去宠物类型字段；生日为空时不能直接回退数据库结构，应先备份并处理这些档案。

分享仍按日期范围和内容分享权限控制，不因新增宠物而放宽权限。公开分享响应不返回孩子或宠物档案；影像中可见的内容和用户填写的标题、日记正文仍需在分享前自行检查。
