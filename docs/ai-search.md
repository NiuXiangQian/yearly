# 一句话找照片、视频

Web、iOS 和 Android 时间线新增「智能找回忆」。输入「去年夏天在海边玩沙子」等描述，结果按相关程度展示，点击沿用现有预览。普通关键词搜索保持原来的语义。

搜索沿用入口的人物、上传人、媒体类型及日期范围。当前智能搜索的日期均指归档日期；语句中的日期进一步收窄范围，包含起止日。人物并列提及时要求同时关联这些档案。自然语言中的“照片”包含 Live Photo 静态照片，显式类型筛选仍保持原有区分。人物身份来自用户已经标记的档案，AI 不做人脸身份识别。

每次最多返回 40 项，从视觉描述向量选出 40 个候选，再筛除不相关结果。大相册应进一步描述场景或缩小范围；本版本不声称完整穷举所有匹配。视频最多抽样 6 帧，可能遗漏短暂动作，不包含语音转写。Live Photo 仅索引静态照片。

## 启用

密钥只放服务端 `.env.test` 或 `.env.production`（Git 忽略、权限 600），不写入 App、网页或仓库：

```dotenv
AI_SEARCH_ENABLED=true
OPENAI_API_KEY=在环境配置中填写
AI_MONTHLY_BUDGET_USD=80
```

默认关闭。启用意味着允许将压缩画面发送至 OpenAI 官方 API。照片只读已生成的展示预览；视频从已生成的压缩视频抽帧，不取冷归档原件。上传和预览任务不等待 AI，旧版 App 的请求与响应保持兼容。

```bash
./scripts/manage.sh test migrate
# 先少量验证，再按批次补建；新上传的内容也由同一任务处理。
./scripts/manage.sh test build-search-index --limit 100
./scripts/manage.sh test build-search-index --limit 100 --retry-failed
# 持续等待新影像，最多处理指定数量后退出。
./scripts/manage.sh test build-search-index --watch --limit 10000
```

生产部署替换为 `production`。可使用 `deploy/yearly-ai-search.service`，修改路径和环境配置后由 systemd 启动。API 与索引进程需要重启才能读取新的环境配置。先启动正常的预览任务，缺少预览的影像会留待后续扫描，不会误标为已经完成。

搜索界面显示当前用户可见的总数、已分析数量；不会把尚未建立索引的影像伪装成可搜索。服务错误与额度不足保留输入，允许稍后重试。后台失败记录需通过 `--retry-failed` 重试，不无限自动消耗额度。

## 模型与成本

固定使用 `gpt-4.1-mini` 生成描述、拆解查询和筛选候选，`text-embedding-3-small` 生成 512 维文本向量。MySQL 存储索引，单家庭规模无需额外向量数据库。

按当前官方标准单价记录 token 费用：GPT-4.1 mini 输入 $0.40 / 百万、输出 $1.60 / 百万；embedding 输入 $0.02 / 百万。按上海时区自然月累计，每次请求预留额度，成功后按 usage 结算，状态不明的失败保留预留额。这个计数是本应用的费用估算，不是 OpenAI 账单；不包含同一密钥在其他应用的用量。价格变更时需同步更新代码。配置预算最高为 $100，默认 $80。

查询通常需要三次 API 调用，反向代理应允许 180 秒读取超时。密钥仅用于 `https://api.openai.com/v1`，不会使用第三方兼容端点。

需要代理时，在服务端环境配置中设置 `OPENAI_PROXY_URL=http://127.0.0.1:7890`，只影响 OpenAI 请求，API 与索引进程共用该设置。留空时沿用进程的标准代理环境变量，依赖也支持 SOCKS。Clash 使用规则模式时，可将 `DOMAIN,api.openai.com,🇯🇵 日本Y04 | IEPL` 放在规则首位，固定使用指定节点；节点凭据和订阅不要写进仓库。容器只有采用 host 网络时才能用上述宿主机回环地址。

## 数据和权限

新增迁移 `0018` 只创建 `media_search_index`、`ai_spend`，不修改现有媒体字段或枚举。原件、用户标题、标签、人物关系均不被 AI 改写。索引在删除媒体行时级联移除；移入回收站或禁止分享后，查询立即按现有权限排除。

候选和关联人物先经过现有 `visible_query` 权限过滤，再交给模型。查询只返回合法候选 ID，返回前再次检查可见性。公共分享链接不能调用智能搜索。只读家庭账号可以搜索自己的可见范围。

索引与本应用费用计数不进入便携影像备份；原始影像和元数据照常备份，恢复后可重建索引。恢复到新站点时请核对 OpenAI 实际账单和剩余额度。
