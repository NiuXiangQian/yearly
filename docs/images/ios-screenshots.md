这组图片用于中英文 README 的原生 App 展示，拍摄于 2026-11-10。使用当前 `ios/Yearly` 源码的独立副本，在 iPhone 18 Pro Max 模拟器中运行实际 SwiftUI 页面；未改变仓库中的产品界面。

- `demo-ios-timeline.png`：家庭时间线、日期分组、搜索与媒体类型筛选。
- `demo-ios-upload.png`：原片批量上传、照片／视频／Live Photo 待确认任务。
- `demo-ios-family.png`：家人与宠物档案。
- `demo-ios-preview.png`：照片全屏预览与浏览序号。
- `demo-ios-share.png`：日期范围、有效期和只读分享说明。
- `demo-ios-account.png`：深色模式下的账号、权限与管理入口。

所有姓名、账号、生日、日期、记录、任务大小与数量均为虚拟数据。插画沿用网页 README 的原创小熊示例素材，经过栅格化供原生图片组件读取。隔离接口只返回本机示例数据，未连接家庭数据库、真实站点或 OSS，未上传原件或创建真实分享链接。

截图使用模拟器原生 3×（1320 × 2868 像素）输出并保存为无损 PNG，没有放大低分辨率截图或拼绘 App 控件。README 仅缩小显示尺寸，点击图片可打开完整分辨率。状态栏统一为 9:41、满电；图片不包含真实设备标识、凭据、GPS 或原片 EXIF。

这些截图展示界面和功能入口，不代表真实相册、iCloud 下载、后台传输或大批量真机上传均已验收。安装方法与实际验证范围见 [iOS 指南](../../ios/README.md)。
